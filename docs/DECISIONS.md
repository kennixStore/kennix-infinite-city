# Project Decisions

A record of important decisions. Status labels matter: **Agreed** means the user selected it; **Proposed** means it still needs discussion.

## Agreed direction

| Topic | Current decision |
|---|---|
| Game title | KENNIX: INFINITE CITY |
| Genre | Open-world action, driving, racing and adventure |
| Delivery target | Browser-playable game |
| 3D technology to prototype | PlayCanvas |
| Vehicle range | Multiple vehicle classes, expanded over time |
| Vehicle damage | Advanced damage is the target |
| Camera | Switchable third-person and first-person |
| Controls | Touch, phone tilt, keyboard and controller goals |
| World inspiration | Mix of real-world-inspired places and fictional cities |
| City progression | Begin in one city; unlock others later |
| Weather | Dynamic weather and environmental effects as a long-term target |
| Multiplayer vision | Offline, friends/private rooms and global competition |
| Progression | Levels, XP, KX, achievements, events and rewards |
| Currency | KX |
| Online crime mechanics | Robbery and vehicle theft are desired, with fair protections |
| Intro | Approximately 60 seconds; cinematic/action mix |
| Working conditions | Android phone only at present; no laptop |

## Proposed, not final

- Slogan: "One City. Endless Possibilities."
- First city name: NOVA CITY.
- District names and layout.
- Blackout opening sequence details.
- Main campaign plot and supporting characters.
- Final logo styling and palette.
- Exact rules for robbing or stealing from online players.
- Specific rewarded-ad provider and monetisation rates.

## Technical guardrails

1. Prove the smallest playable driving loop before expanding scope.
2. Keep this game repository separate from KENNIX Store.
3. Never treat client-side currency values as authoritative for online play.
4. Never claim planned features are already implemented.
5. Test on real Android hardware early.
6. Do not copy another game's protected assets or distinctive presentation.
